# RCA-RL source

The RCA-RL policy network and agent-selection logic are adapted from [HeteroMRTA](https://github.com/marmotlab/HeteroMRTA), associated with the paper [Heterogeneous Multi-robot Task Allocation and Scheduling via Reinforcement Learning](https://www.marmotlab.org/publications/73-RAL2025-HetMRTA.pdf). The original code is licensed under Apache-2.0; see `THIRD_PARTY_LICENSE`.

This project retains the network, single-instance policy rollout, and simulation methods needed to evaluate the bundled model on AHD-RL instances.
